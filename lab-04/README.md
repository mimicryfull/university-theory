# Лабораторна 4. Методи обчислення середніх величин

Номер у журналі N = **1**; вибірка містить **3000** випадкових цілих чисел
у діапазоні **1..5**. Використано Python 3 та лише стандартну бібліотеку.

## Запуск

```bash
uv run python main.py --student-number 1 --seed 20260401
```

Для друку повних початкової і впорядкованої вибірок у терміналі додати
`--print-sample`. Повні дані також доступні в CSV, JSON та HTML.

## Результати

- `results.json` — параметри, обидві вибірки, частоти, шість середніх і дисперсія.
- `sample.csv` — усі 3000 чисел у початковому порядку.
- `sorted_sample.csv` — усі 3000 чисел у порядку неспадання з рангами.
- `sorted_sample.txt` — та сама впорядкована вибірка по 30 чисел у рядку.
- `frequencies.csv` — абсолютні й відносні частоти, інтервали рангів.
- `histogram.svg` — векторний частотний графік, не скриншот.
- `results.html` — сторінка для перегляду графіка, середніх та повних вибірок.
- `report.typ`, `report.pdf` — звіт; його таблиці беруть дані з `results.json`.

Для перегляду відкрити `results.html` у браузері або `report.pdf` у PDF-переглядачі.

## Збірка звіту

З кореня репозиторію:

```bash
typst compile --root . lab-04/report.typ lab-04/report.pdf
```

Геометричне середнє обчислюється через логарифми, щоб не перемножувати
3000 чисел. Якщо кілька чисел мають однакову найбільшу частоту, виводяться
всі моди. Для парної кількості значень медіана є середнім двох центральних;
обидві центральні порядкові статистики збережені окремо.

Ці запуски створюють результати виконання завдання. Тести й окремі перевірки
за вказівкою користувача не запускались.
