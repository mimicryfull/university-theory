# Лабораторна робота № 7 — Метод ідеальної точки

Біжик Юрій Володимирович, ФЕІ-34с. Теорія прийняття рішень,
кафедра оптоелектроніки та інформаційних технологій. Варіант N = 1.
Викладачка: доцент Дуфанець Марта Василівна.

Завдання взято з `../Lab7.pdf`. Програма формує 10 пар цілих координат
у межах N−3..N+3 (для N=1: −2..4), максимізує Q1=x1 і Q2=x2,
знаходить Парето-множину, оптимуми згортки 0,3Q1+0,7Q2 та найближчі
до ідеальної точки альтернативи за евклідовою метрикою. Нормування
методичка не задає; використано початкові координати в однакових шкалах.
Всі нічиї зберігаються. Порівняння згорток і квадратів відстаней точні,
цілочислові; округлення у звіті стосується тільки відображення.

## Запуск

Потрібен Python 3.9+; сторонні пакети не потрібні.

```bash
cd /home/katanix/Documents/LNU/Theory/lab-07
uv run python main.py --student-number 1
typst compile --root .. report.typ report.pdf
```

За замовчуванням seed = 7007. Його можна змінити через `--seed 42`.
Власні координати задаються файлом JSON: масив 10 масивів із двох
цілих чисел у діапазоні N−3..N+3:

```bash
uv run python main.py --student-number 1 --input coordinates.json
```

Параметр `--output-dir` змінює каталог результатів. Для складання
наданого звіту результати мають лежати поряд із `report.typ`.

## Файли

- `main.py` — генерація, всі три методи та векторний графік.
- `results.json` — параметри, масив `alternatives`, координати `ideal`,
  множини `pareto_ids`, `linear_ids`, `ideal_ids`, найкращі значення.
  Кожна альтернатива містить індекс, координати, оцінки, домінаторів,
  належність до Парето, згортку, відстань та її квадрат.
- `alternatives.csv` — таблиця координат і результатів.
- `alternatives.svg` — програмно створений графік, не знімок екрана;
  однакові координати позначені однією точкою з усіма індексами.
- `report.typ` — український звіт зі спільною титульною сторінкою,
  формулами, таблицею, графіком та висновками із JSON-результатів.
- `report.pdf` — результат складання Typst.

`results.json`, CSV і SVG створюються запуском програми; PDF — запуском
Typst. Звіт потребує цих результатів і шрифту Literata зі спільного шаблону.
Скріншоти й тестові перевірки не передбачено за вказівкою користувача.
