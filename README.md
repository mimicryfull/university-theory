## Виконання через uv

Потрібні [uv](https://docs.astral.sh/uv/) та Python 3.11 або новіший.
Python-залежностей поза стандартною бібліотекою немає. З кореня репозиторію:

```bash
uv sync --locked
uv run python run_all.py
```

Окремі роботи також запускаються з кореня:

```bash
uv run python labs/lab-04/src/main.py --student-number 1 --seed 20260401
uv run python labs/lab-07/src/main.py --student-number 1
uv run python labs/lab-10/src/main.py --variant 1
```

За замовчуванням дані записуються в `data/`, SVG — у `figures/` відповідної
роботи незалежно від поточної папки. Параметр `--figures-dir` задає інший
каталог рисунків. `src/charts.py` дозволяє регенерувати тільки графіки
зі збережених числових результатів:

```bash
uv run python labs/lab-04/src/charts.py
```

`run_all.py` виконує завдання. Зерна генераторів зафіксовано для відтворюваності.
Вхідні `data/input.json` у роботах 5, 9, 10 можна змінювати для інших
навчальних наборів.

## Збірка PDF та шрифти

Потрібні компілятор [Typst](https://typst.app/) та встановлені **Literata**
і **MonoLisaCode**. Формули використовують **STIX Two Math**, який зберігається
в `fonts/` разом із ліцензією SIL OFL 1.1; джерело й версія наведені у
[fonts/README.md](fonts/README.md). Скрипт передає `--font-path fonts`.
Файли MonoLisaCode у репозиторій не включені.

Код та inline-фрагменти набираються MonoLisaCode. Для блоків із мовою
задана читабельна світла тема [code-light.tmTheme](report-template/code-light.tmTheme).
Кожен рисунок і таблиця мають нумерований підпис знизу: 6 pt від
об’єкта до підпису та 12 pt після об’єкта з підписом.
Основний текст — Literata; параметри оформлення зберігаються окремо в
[rules.typ](report-template/rules.typ), пояснення — у [RULES.md](report-template/RULES.md).

```bash
uv run python build_reports.py
```

Якщо компілятор розташований поза PATH:

```bash
uv run python build_reports.py --typst /шлях/до/typst
```

Готові PDF збережені в репозиторії. Звіти читають збережені результати;
після зміни вхідних даних потрібно виконати відповідну програму та зібрати PDF.
