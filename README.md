## Запуск через uv

Потрібні [uv](https://docs.astral.sh/uv/) і Python 3.11 або новіший.
Python-залежностей поза стандартною бібліотекою немає. Запуск із кореня:

```bash
uv sync --locked
uv run python run_all.py
```

Або окремо, наприклад:

```bash
uv run python lab-04/main.py --student-number 1 --seed 20260401
uv run python lab-07/main.py --student-number 1
uv run python lab-10/main.py --variant 1
```

`run_all.py` виконує завдання, а не тести. Результати пишуться в папки робіт;
початкові стани генератора зафіксовані для відтворюваності. Вхідні JSON у
роботах 5, 9, 10 можна змінювати для інших навчальних задач.

## Збірка звітів

Потрібні компілятор Typst і шрифти **Literata**, **Liberation Mono**.
На Arch/CachyOS Typst доступний як системний пакет `typst`.

```bash
uv run python build_reports.py
```

Якщо компілятор розташований поза PATH:

```bash
uv run python build_reports.py --typst /шлях/до/typst
```

Готові PDF вже збережені в репозиторії. Спільна верстка — в
`_report-template/template.typ`, параметри — в `_report-template/rules.typ`,
правила — окремим файлом [_report-template/RULES.md](_report-template/RULES.md).
Звіти читають збережені результати; після зміни вхідних даних треба виконати
програму відповідної роботи й повторно зібрати PDF.
