# Лабораторна робота 5 — методи експертного оцінювання

Три аналітичні методи та обґрунтування методу Терстоуна наведені в `report/report.typ`.
`src/main.py` обчислює шкалу Терстоуна методом найменших квадратів, друкує ранжування
і зберігає повні результати в JSON. Залежності: Python 3, стандартна бібліотека.

```bash
cd /home/katanix/Documents/LNU/Theory/labs/lab-05
uv run python src/main.py --input data/input.json --output data/results.json
typst compile report/report.typ report/report.pdf --root ../.. --font-path ../../fonts
```

`data/input.json` містить явно навчальні синтетичні альтернативи й імовірності.
Їх потрібно замінити, якщо викладач надасть свій набір або фактичне опитування.
Оцінки `churchman_final` — прийнята корекція суджень навчального експерта;
програма не вигадує і не автоматизує його рішення. Результати щодо цього набору
не є рекомендацією щодо реальних ноутбуків. Журнальний номер для цієї роботи не потрібний.

`src/charts.py` створює `figures/expert-methods.svg`, `figures/thurstone-scale.svg` та
`figures/pairwise-probabilities.svg`; викликається автоматично з `src/main.py`.
Для рисунків із наявних `data/results.json` та `data/input.json`:

```bash
uv run python src/charts.py
```

Порівняння аналітичних методів використовує окреме min-max масштабування
кожної шкали лише для візуалізації. Адитивні судження Черчмена–Акоффа
обчислюються у початковій шкалі без віднімання мінімуму.

## Організація

`src/` містить Python-код; `data/` — вхідні дані й числові результати; `figures/` — SVG; `report/` — Typst і PDF. Команди для цієї роботи виконувати з її кореневої папки. Значення `--figures-dir` можна задати окремо; типово рисунки потрапляють у `figures/`, а числові результати — у `data/`.
