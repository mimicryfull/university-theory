# Лабораторна 4. Методи обчислення середніх величин

Номер у журналі N = **1**; вибірка містить **3000** випадкових цілих чисел
у діапазоні **1..5**. Використано Python 3 та лише стандартну бібліотеку.

## Запуск

```bash
uv run python src/main.py --student-number 1 --seed 20260401
```

Для друку повних початкової і впорядкованої вибірок у терміналі додати
`--print-sample`. Повні дані також доступні в CSV, JSON та HTML.

## Результати

- `data/results.json` — параметри, обидві вибірки, частоти, шість середніх і дисперсія.
- `data/sample.csv` — усі 3000 чисел у початковому порядку.
- `data/sorted_sample.csv` — усі 3000 чисел у порядку неспадання з рангами.
- `data/sorted_sample.txt` — та сама впорядкована вибірка по 30 чисел у рядку.
- `data/frequencies.csv` — абсолютні й відносні частоти, інтервали рангів.
- `figures/histogram.svg` — векторний частотний графік, не скриншот.
- `index.html` — сторінка для перегляду графіка, середніх та повних вибірок.
- `report/report.typ`, `report/report.pdf` — звіт; його таблиці беруть дані з `data/results.json`.

Для перегляду відкрити `index.html` у браузері або `report/report.pdf` у PDF-переглядачі.

## Збірка звіту

З кореня репозиторію:

```bash
typst compile --root . --font-path fonts labs/lab-04/report/report.typ labs/lab-04/report/report.pdf
```

Геометричне середнє обчислюється через логарифми, щоб не перемножувати
3000 чисел. Якщо кілька чисел мають однакову найбільшу частоту, виводяться
всі моди. Для парної кількості значень медіана є середнім двох центральних;
обидві центральні порядкові статистики збережені окремо.

Ці запуски створюють результати виконання завдання. Тести й окремі перевірки
за вказівкою користувача не запускались.

Додаткові векторні рисунки з тих самих даних: `figures/empirical-cdf.svg`,
`figures/means-comparison.svg`, `figures/sample-boxplot.svg`. Їх створює `src/charts.py`, який
також викликається з `src/main.py`. Для регенерації лише рисунків зі збереженого JSON:

```bash
uv run python src/charts.py
```

Квартилі boxplot обчислюються методом `inclusive`, вуса визначені правилом 1.5 IQR.

## Організація

`src/` містить Python-код; `data/` — вхідні дані й числові результати; `figures/` — SVG; `report/` — Typst і PDF. Команди для цієї роботи виконувати з її кореневої папки. Значення `--figures-dir` можна задати окремо; типово рисунки потрапляють у `figures/`, а числові результати — у `data/`.
