# Лабораторна 1. Розподіли випадкових величин

Варіант **N=1**. Сім розподілів за методичкою: Бернуллі, біноміальний,
Пуассона, рівномірний, нормальний, Парето та Стьюдента.
Python 3 і стандартна бібліотека; сторонні пакети не потрібні.

## Запуск

Із папки роботи:

```bash
uv run python src/main.py --student-number 1 --input data/input.json
```

Без `--input` параметри автоматично обчислюються за формулами методички
для заданого `--student-number`. JSON дає змогу ввести параметри вручну.
Теоретичні функції обчислюються без генерування випадкових вибірок.

## Результати

- `data/input.json` — параметри індивідуального варіанта.
- `data/results.json` — всі параметри, моменти, значення PMF/PDF та CDF.
- `data/*.csv` — числові таблиці семи розподілів.
- `figures/*.svg` — сім рисунків PMF/PDF+CDF і порівняння правих хвостів.
- `index.html` — сторінка перегляду рисунків.
- `report/report.typ`, `report/report.pdf` — звіт із даними фактичного запуску.

Регенерація лише графіків: `uv run python src/charts.py`.

## Збірка звіту

Із кореня репозиторію:

```bash
typst compile --root . --font-path fonts labs/lab-01/report/report.typ labs/lab-01/report/report.pdf
```

## Особливості варіанта

Пуассон із λ=11 зображається лише на k=0..6: це приблизно 7.8614% маси,
без перенормування. Стьюдент ν=1 є Коші зі сподіванням, що не існує;
Парето α=1 має нескінченне сподівання. Скінченної дисперсії немає в обох.
У густині Парето використано правильну підтримку x≥x₀; у методичці
нерівність надрукована навпаки. Для нормального закону 0.5 — дисперсія,
а не стандартне відхилення.

`src/`, `data/`, `figures/`, `report/` відокремлюють код, числові дані,
векторні рисунки та оформлений звіт. Програму виконано для отримання результатів.
Тести, скриншоти та візуальні перевірки не виконувалися.
