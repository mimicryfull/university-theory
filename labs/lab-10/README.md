# Лабораторна робота № 10

Матричні ігри та всі сідлові точки. Біжик Юрій Володимирович, ФЕІ-34с; номер у журналі / варіант **1**.

З папки `lab-10`:

```sh
uv run python src/main.py --variant 1 --input data/input.json --output-dir data
typst compile report/report.typ report/report.pdf --root ../.. --font-path ../../fonts
```

Python 3, стандартна бібліотека. Рядки — перший гравець (максимізує), стовпці — другий (мінімізує). Пошук повертає **всі** сідлові точки, координати починаються з 1. За відсутності точки `pure_value` дорівнює `null`, нижня/верхня ціни зберігаються окремо. Для 2×2 додатково обчислюються змішані стратегії, якщо є внутрішня змішана рівновага.

Монети варіанта 1: `[[2, -1], [-3, 1]]`; сідлової точки немає, α = −1, β = 1. Власна контрактна гра має точки (2, 1) та (2, 3), ціну 3. Власна гра алгоритмів стиснення не має сідла, α = −1, β = 3. Таблиці власних ігор — явно вигадані контрактні платежі, не вимірювання.

`data/results.json` містить повні числові результати та використовується звітом; `data/results.csv` — підсумок. Замість скриншотів наведено таблиці чисел відповідно до вказівки користувача.

## Додаткові векторні графіки

`figures/payoff-1.svg`, `figures/payoff-2.svg`, `figures/payoff-3.svg` — теплокарти платежів із числами, граничними оцінками та всіма сідловими точками.

`src/charts.py` формує SVG стандартною бібліотекою Python із реальних числових
результатів. `src/main.py` викликає його автоматично. Для оновлення лише
графіків зі збереженого `data/results.json`:

```bash
uv run python src/charts.py
```

Графіки включено у звіт; знімки екрана не використовуються.

## Організація

`src/` містить Python-код; `data/` — вхідні дані й числові результати; `figures/` — SVG; `report/` — Typst і PDF. Команди для цієї роботи виконувати з її кореневої папки. Значення `--figures-dir` можна задати окремо; типово рисунки потрапляють у `figures/`, а числові результати — у `data/`.
