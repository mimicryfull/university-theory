# Лабораторна 2 — Бінарні відношення та основні операції над ними

Біжик Юрій Володимирович · ФЕІ-34с · варіант 1.
Кафедра оптоелектроніки та інформаційних технологій.
Теорія прийняття рішень. Викладачка: доцент Дуфанець Марта Василівна.

За `materials/Lab2.pdf` носій має порядок {зима, весна, літо, осінь}.
P означає «не холодніше», Q — «так само». Весна та осінь вважаються
однаковими за температурним порядком: рівні 0, 1, 2, 1 є порядковими
кодами, а не фізичними температурами.

Програма вводить відношення, знаходить області визначення й значень,
обчислює перетин, об'єднання, різницю, симетричну різницю,
доповнення відносно A×A, обернення P, композицію P○Q.
Додатково виводяться Q\P, доповнення Q, Q○P та P².
Порядок композиції відповідає методичці: спочатку P, потім Q.

З кореня репозиторію:

```bash
uv run python labs/lab-02/src/main.py --variant 1
uv run python labs/lab-02/src/charts.py
typst compile --root . --font-path fonts labs/lab-02/report/report.typ labs/lab-02/report/report.pdf
```

Стандартна бібліотека Python, зовнішніх залежностей немає.
Варіанти 1–16 змінюють порядок сезонів згідно з таблицею методички.
Для введення власних відношень JSON має містити `names`, квадратні
матриці 0/1 `P` і `Q`:

```bash
uv run python labs/lab-02/src/main.py --input labs/lab-02/data/input.json
```

`--output-dir` задає каталог JSON/CSV, `--figures-dir` — каталог SVG.
Звіт призначений для сезонної задачі; після зміни даних його треба зібрати
повторно. Власні відношення змінюють числові результати; аналітичні
пояснення сезонної задачі для довільних відношень не застосовуються.

- `src/main.py` — основні операції над множинами пар, CLI, CSV/JSON/HTML.
- `src/charts.py` — матриці P/Q, матриці операцій та діаграма кількості пар.
- `data/input.json` — використані вхідні матриці й порядкові рівні.
- `data/results.json` — матриці, впорядковані пари, області, кількість пар.
- `data/pairs.csv` — усі пари для кожного відношення.
- `data/summary.csv` — кількості пар та області визначення/значень.
- `figures/` — три SVG, створені програмно з результатів.
- `report/` — український Typst-звіт і PDF зі спільним оформленням Literata.
- `index.html` — локальна сторінка з рисунками, підписами та посиланням на PDF.

Звіт містить аналітичне обґрунтування, усі матриці, рисунки з підписами
і лістинг виконавчої частини. За вказівкою користувача скриншоти,
окремі тести та візуальний перегляд не виконувалися.
