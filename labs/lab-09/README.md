# Лабораторна робота № 9

Метод аналітичної ієрархії для вибору резервного копіювання: 5 критеріїв, 5 альтернатив, навчальні судження шкали Сааті. Студент: Біжик Юрій Володимирович, ФЕІ-34с.

З папки `lab-09`:

```sh
uv run python src/main.py --input data/input.json --output-dir data
typst compile report/report.typ report/report.pdf --root ../.. --font-path ../../fonts
```

Python 3, без сторонніх бібліотек. Матриці можна задати як `matrix` замість `scores`. Програма виводить кожну матрицю, локальні ваги (степеневий метод і геометричне наближення), λmax, CI, RI, CR, глобальні ваги, ранжування та агреговану узгодженість. Строгий поріг CR ≤ 0,1 застосовується окремо до кожної матриці. `data/results.json` використовується звітом; `data/ranking.csv` містить підсумок. `figures/hierarchy.svg` — векторна ієрархія, а не знімок екрана.

Оцінки умовні, отримані не опитуванням, а перетворенням явно наведених навчальних балів у округлені судження шкали Сааті. Для вартості більший бал означає доступніше рішення. Низький CR не доводить об’єктивної правильності оцінок.

## Додаткові векторні графіки

`figures/priorities.svg` — ваги критеріїв і ранжування; `figures/consistency.svg` — CR усіх матриць із порогом 0,10.

`src/charts.py` формує SVG стандартною бібліотекою Python із реальних числових
результатів. `src/main.py` викликає його автоматично. Для оновлення лише
графіків зі збереженого `data/results.json`:

```bash
uv run python src/charts.py
```

Графіки включено у звіт; знімки екрана не використовуються.

## Організація

`src/` містить Python-код; `data/` — вхідні дані й числові результати; `figures/` — SVG; `report/` — Typst і PDF. Команди для цієї роботи виконувати з її кореневої папки. Значення `--figures-dir` можна задати окремо; типово рисунки потрапляють у `figures/`, а числові результати — у `data/`.
