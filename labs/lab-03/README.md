# Лабораторна 3. Агрегування та факторизація

Біжик Юрій Володимирович, ФЕІ-34с; номер у журналі **N=1**. Викладач — доцент Дуфанець Марта Василівна.

Використано приклад матриці з пункту 2 [методички](../../materials/Lab3.pdf), оскільки окрему матрицю викладача не надано. Кількість зсувів N−1 = 0.

З кореня репозиторію:

```bash
uv run python labs/lab-03/src/main.py --student-number 1
uv run python labs/lab-03/src/charts.py
```

Python використовує стандартну бібліотеку. Програма обчислює булеві степені до першого повторення будь-якої попередньої матриці, транзитивне замикання, досяжність, взаємну досяжність, класи еквівалентності, фактор-матрицю й конденсацію без петель.

`--input` дозволяє задати JSON із полем `base_matrix`; `--output-dir` змінює каталог числових даних, `--figures-dir` — SVG. Для іншого N режим `--shift-mode flat` зсуває всю послідовність елементів по рядках, `rows` — кожний рядок. Для N=1 відмінність відсутня. `--max-powers` задає межу пошуку повторення, типово 10 000; перевищення дає помилку замість неповного замикання.

## Артефакти

- `src/main.py`, `src/charts.py` — обчислення та SVG.
- `data/input.json` — вихідна матриця й джерело.
- `data/results.json` — степені та всі похідні відношення.
- `data/*.csv` — шість матриць і класи.
- `figures/initial-graph.svg`, `relation-matrices.svg`, `factor-graph.svg`, `condensation.svg` — чотири векторні рисунки.
- [index.html](index.html) — таблиці та графи з нижніми підписами.
- [report/report.typ](report/report.typ), [report/report.pdf](report/report.pdf) — звіт у спільному оформленні.

Результат факторизації — один клас `{x1,x2,x3,x4}`, фактор-матриця `[[1]]`, конденсація `[[0]]`. Петлю екзистенційного фактор-відношення явно відокремлено від ациклічного графа конденсації.

Збірка окремого PDF з кореня через наявний Typst:

```bash
typst compile --root . --font-path fonts labs/lab-03/report/report.typ labs/lab-03/report/report.pdf
```

Програму виконано для отримання фактичних чисел і рисунків; PDF зібрано. Тести, скриншоти та візуальний перегляд PDF за вказівкою користувача не проводяться.
