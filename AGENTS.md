# Теорія прийняття рішень — лабораторні роботи

Користувач: Біжик Юрій Володимирович, ФЕІ-34с, номер у журналі N = 1.
Кафедра: оптоелектроніки та інформаційних технологій.
Викладач: доцент Дуфанець Марта Василівна.

Умови — у відповідних LabN.pdf; виконання — у lab-NN/.
Звіти Typst використовують _report-template/template.typ, Literata 14 pt.
Правила оформлення збережені окремо в _report-template/RULES.md і rules.typ.

Для цієї роботи користувач прямо попросив паралельних агентів, один спільний
коміт, без скриншотів і перевірок. Не запускати тести або візуальну перевірку.
Усі Python-програми запускати через uv: `uv run python ...`; залежності й
оточення керуються спільними `pyproject.toml` та `uv.lock`.
Запуск розв'язків для отримання розрахунків і збірка звітів є виконанням завдання.
Не стверджувати, що тести пройдені, якщо їх не запускали.

Набір альтернатив викладача для лабораторної 5 не надано; навчальний набір
позначати саме як навчальний, не приписувати його викладачеві чи реальним експертам.
Зміни всіх лабораторних збирає основний агент в один коміт.
