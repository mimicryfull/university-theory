# Теорія прийняття рішень — лабораторні роботи

Користувач: Біжик Юрій Володимирович, ФЕІ-34с, номер у журналі N = 1.
Кафедра: оптоелектроніки та інформаційних технологій.
Викладач: доцент Дуфанець Марта Василівна.

Умови зберігаються у `materials/LabN.pdf`. Виконання — у `labs/lab-NN/`:
`src/` для Python-коду, `data/` для JSON/CSV/TXT, `figures/` для векторних
SVG, `report/` для Typst/PDF. У лабораторній №4 `index.html` міститься
в корені її папки та посилається на `figures/`.

Звіти імпортують `../../../report-template/template.typ` з папки `report/`.
Основний текст — Literata 14 pt; код та inline-фрагменти — встановлена
MonoLisaCode зі світлою підсвіткою `code-light.tmTheme`; формули — STIX Two Math.
STIX поставляється в `fonts/` разом із ліцензією SIL OFL 1.1. Не копіювати
локальні файли MonoLisaCode до репозиторію. Правила оформлення — у
`report-template/RULES.md` та `report-template/rules.typ`.

Користувач прямо попросив паралельних агентів і один спільний коміт усіх
правок поточного завдання. Push до `origin/main` авторизований користувачем.
Не переписувати попередні коміти. Координувати області файлів між агентами.

Не робити скриншотів, тестів, окремих перевірок або візуального перегляду PDF.
Запуски розв’язків для отримання чисел/графіків та збірка PDF є виконанням
завдання. Виправляти помилки виконання чи компіляції, якщо вони виникають.
Не заявляти, що тести пройдені.

Усі Python-програми запускати через uv: `uv run python ...`; залежності
та оточення керуються спільними `pyproject.toml` і `uv.lock`.
З кореня: `uv run python run_all.py`, потім
`uv run python build_reports.py [--typst /шлях/до/typst]`.
Вихідні файли не записувати поруч зі скриптами у `src/`.

Набір альтернатив викладача для №5 не надано; позначати набір як навчальний,
не приписувати його викладачеві чи реальним експертам. У №9 також використано
явно умовні судження для самостійно обраної задачі. Варіант №10 — 1.
