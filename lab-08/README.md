# Лабораторна робота № 8 — Лексикографічний метод і послідовні поступки

Біжик Юрій Володимирович, ФЕІ-34с. Теорія прийняття рішень,
кафедра оптоелектроніки та інформаційних технологій. Варіант N = 1.
Викладачка: доцент Дуфанець Марта Василівна.

Завдання взято з `../Lab8.pdf`: N+3 альтернатив (для N=1 — 4),
чотири критерії, оцінки 0..5, усі критерії максимізуються.
Ілюстративна таблиця методички з оцінками до 9 не використовується,
оскільки суперечить заданому діапазону.

Лексикографічні порядки: Q2,Q1,Q3,Q4 і Q4,Q1,Q2,Q3.
Послідовні поступки: порядок Q1,Q2,Q3,Q4; поступки 1,2,3.
Кожний максимум знаходиться у поточній допустимій множині;
після нього лишаються оцінки не менші за максимум мінус поступка.
Вилучені через попередні обмеження альтернативи не повертаються.
За четвертим критерієм обираються всі точні максимуми.

## Запуск

Потрібен Python 3.9+; сторонні пакети не потрібні.

```bash
cd /home/katanix/Documents/LNU/Theory/lab-08
uv run python main.py --student-number 1
typst compile --root .. report.typ report.pdf
```

Seed за замовчуванням — 8008; інше значення задається через `--seed 42`.
Можна ввести власну JSON-матрицю з N+3 рядків по 4 цілі оцінки 0..5:

```bash
uv run python main.py --student-number 1 --input criteria.json
```

`--output-dir` задає каталог результатів. Для складання наданого звіту
результати мають лежати поряд із `report.typ`.

## Файли

- `main.py` — генерація таблиці та реалізація обох методів.
- `results.json` — параметри, `alternatives` (індекс і 4 критерії),
  два проходи `lexicographic` і один `concessions`.
  Кожний прохід містить порядок, `steps` і всі `winner_ids`;
  крок містить `criterion`, `before_ids`, `optimum`, `retained_ids`;
  для поступок також `delta` та `threshold`.
- `alternatives.csv` — таблиця оцінок із рядком на альтернативу.
- `steps.csv` — повний протокол звуження множини для трьох проходів.
- `report.typ` — український звіт зі спільним шаблоном, формулами,
  таблицями даних і всіх кроків, результатами та висновками.
- `report.pdf` — результат складання Typst.

JSON і CSV створюються виконанням програми, PDF — складанням Typst.
Звіт автоматично читає `results.json`; перед його складанням слід
виконати програму. Використовується шрифт Literata зі спільного шаблону.
Нічиї на будь-якому кроці зберігаються повністю. Скріншоти й тестові
перевірки не передбачено за вказівкою користувача.
