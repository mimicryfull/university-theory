# Шрифт формул

`STIXTwoMath-Regular.otf` — STIX Two Math v2.13 b171, офіційний OpenType MATH шрифт.

Джерело: [STIX Fonts](https://github.com/stipub/stixfonts/tree/v2.13b171), архів [static_otf.zip](https://raw.githubusercontent.com/stipub/stixfonts/v2.13b171/zipfiles/static_otf.zip).

Ліцензія: SIL Open Font License 1.1, повний текст у [OFL.txt](OFL.txt). Шрифт дозволено включати в репозиторій та вбудовувати в PDF за умовами ліцензії.

Основний текст використовує встановлену Literata; код — встановлену MonoLisaCode. Файли MonoLisaCode у репозиторій не копіюються.
