# Лабораторна робота № 9

Метод аналітичної ієрархії для вибору резервного копіювання: 5 критеріїв, 5 альтернатив, навчальні судження шкали Сааті. Студент: Біжик Юрій Володимирович, ФЕІ-34с.

З папки `lab-09`:

```sh
uv run python main.py --input input.json --output-dir .
typst compile report.typ report.pdf --root ..
```

Python 3, без сторонніх бібліотек. Матриці можна задати як `matrix` замість `scores`. Програма виводить кожну матрицю, локальні ваги (степеневий метод і геометричне наближення), λmax, CI, RI, CR, глобальні ваги, ранжування та агреговану узгодженість. Строгий поріг CR ≤ 0,1 застосовується окремо до кожної матриці. `results.json` використовується звітом; `ranking.csv` містить підсумок. `hierarchy.svg` — векторна ієрархія, а не знімок екрана.

Оцінки умовні, отримані не опитуванням, а перетворенням явно наведених навчальних балів у округлені судження шкали Сааті. Для вартості більший бал означає доступніше рішення. Низький CR не доводить об’єктивної правильності оцінок.
