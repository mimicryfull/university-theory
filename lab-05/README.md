# Лабораторна робота 5 — методи експертного оцінювання

Три аналітичні методи та обґрунтування методу Терстоуна наведені в `report.typ`.
`main.py` обчислює шкалу Терстоуна методом найменших квадратів, друкує ранжування
і зберігає повні результати в JSON. Залежності: Python 3, стандартна бібліотека.

```bash
cd /home/katanix/Documents/LNU/Theory/lab-05
uv run python main.py --input input.json --output results.json
typst compile report.typ report.pdf --root ..
```

`input.json` містить явно навчальні синтетичні альтернативи й імовірності.
Їх потрібно замінити, якщо викладач надасть свій набір або фактичне опитування.
Оцінки `churchman_final` — прийнята корекція суджень навчального експерта;
програма не вигадує і не автоматизує його рішення. Результати щодо цього набору
не є рекомендацією щодо реальних ноутбуків. Журнальний номер для цієї роботи не потрібний.
